# Урок QA — Граничные данные
[[Урок QA — Поиск расхождения|← Расхождение]] · [[Интерактивный практикум|Маршрут]] · [[Урок QA — Воспроизводимый баг|Далее →]]
**Цель:** выбирать входы по причине, а не по количеству.

## Контракт P1
Для учебной модели «Просачивания» вход x — **целое число от 0 до 12 включительно**. Результат — floor(x / 2); остальные входы отклоняются. Floor округляет вниз: 5 / 2 = 2,5 → 2. Здесь не моделируются разрывы, триггеры срыва или изменение шкалы. [[Учебные модели проектов#P1 — сила срыва «Просачивания»|Источник условия]].

Граница — место, где меняется правило. Между −1 и 0 отказ сменяется вычислением. Между 12 и 13 вычисление сменяется отказом. Числа 4, 6, 8 лежат внутри одного допустимого класса: три похожих теста не заменяют проверку отказа.

## Разобранный пример
Для минимума 0 возьми −1, 0, 1: ниже границы, сама граница, сразу выше. Ожидается: отказ, 0, 0. Последний случай также отличает округление вниз от округления вверх.

## Выбери набор
Цель: обе границы, дробный ввод и нечётное значение. Запиши выбор и причины **в своей заметке**, затем открой соответствующий разбор:
- [[Разбор QA — Первый модуль#Набор из середины|4, 6, 8]]
- [[Разбор QA — Первый модуль#Только крайние допустимые|0, 12]]
- [[Разбор QA — Первый модуль#Набор с соседями и дробью|−1, 0, 1, 11, 12, 13, 2,5]]

Теперь составь таблицу «вход → ожидание → причина выбора» и вычисли ответы вручную. Для отказа запиши, какое условие нарушено. [[Разбор QA — Первый модуль#Ожидания P1|Сверить ожидания]].

> [!tip]- Почему дробь — отдельная проверка
> 2,5 находится внутри числового диапазона, но нарушает требование целочисленности. Проверка диапазона и проверка типа/формата — не одно и то же.

## Ловушка: число или строка
Число `6` и строка `"6"` — разные входы в программную функцию. По P1 первое допустимо, второе нет. Если интерфейс преобразует текст в число, нужен отдельный контракт этого интерфейса. Не выводи поведение формы из контракта функции.

- [ ] Для каждого входа объяснил причину выбора.
- [ ] Различил выход за диапазон и нарушение целочисленности.
- [ ] Не назвал выбранный набор полным покрытием всех ошибок.
