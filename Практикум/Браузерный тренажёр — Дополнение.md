# Браузерный тренажёр — Дополнение
Основной путь первого модуля — [[Интерактивный практикум]] **внутри Obsidian**. Этот стенд дополнительный: он позволяет самостоятельно запускать переходы, а не только анализировать подготовленные трассы. Он не нужен, чтобы выполнить четыре урока и написать отчёт в vault.

## Открыть по желанию
В проводнике открой `trainer/index.html` внутри папки хранилища обычным браузером. Сервер, Node.js и плагины Obsidian не нужны. [Файл стенда](../trainer/index.html). Если Obsidian показывает код, используй проводник. На GitHub HTML тоже показывается исходным кодом: сначала скачай/обнови локальную копию репозитория.

## Разница с заметками
- Браузер выполняет учебную модель и автоматически сравнивает выбранный вывод с C1.
- Obsidian хранит условия, подготовленные наблюдения, ветки разбора и твою тетрадь; автоматической оценки там нет.
- Проверка формы в браузере определяет только наличие текста, а не истинность баг-репорта.
- Источник контракта один: [[Учебные модели проектов]]. Ошибки A/B намеренно созданы для обучения.

## Данные и сохранение
Браузерный прогресс хранится отдельно, только в этом браузере. Он не синхронизируется с [[Прогресс]] и не заполняет тетрадь. При желании скачай Markdown и перенеси его в `Практика`. Резервная копия JSON сохраняет прогресс и черновик; очистка браузера или смена пути файла может потерять локальные данные. Последнее наблюдение стенда между перезагрузками не сохраняется: сначала вставь его в черновик.

Ни этот стенд, ни подготовленные трассы не подтверждают поведение настоящего RPG Codex. [[Интерактивный практикум|Вернуться к основному маршруту в Obsidian]].
