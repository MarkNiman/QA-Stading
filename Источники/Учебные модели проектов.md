# Учебные модели проектов
Эти контракты созданы для упражнений. Они не описывают проверенную текущую реализацию проектов и не изменяют их канон.

## C1 — очередь RPG Codex
- state: participants — массив уникальных непустых строк; activeIndex — целый индекс; round — положительное целое число.
- Для пустого массива activeIndex равен null.
- Допустимые роли: gm и player. Только gm может переключать ход.
- Пустая очередь не допускает переключения.
- Обычный переход увеличивает индекс; последний возвращает индекс 0 и увеличивает раунд.
- Функция возвращает новый объект и копию массива. Исходное состояние не меняется.
- Ошибки входа вызывают исключение. Для запрещённой роли проверка роли предшествует проверке состояния.
- Строковые имена здесь служат идентификаторами: совпадающие имена не допускаются. В настоящем приложении нужны отдельные ID, допускающие одинаковые отображаемые имена.

## C2 — вымышленный API поверх C1
POST /training/encounters/demo/advance — адрес только в статье, сервер не реализован.
Роль берётся из серверной сессии. Тело содержит expectedVersion. Успех — 200 и версия +1; запрещённая известная роль — 403; устаревшая версия — 409. Отказы не меняют состояние.
Приоритет ответа при нескольких одновременных ошибках не задан. Формат прочих ошибок не задан.

## P1 — сила срыва «Просачивания»
Для целого числового x от 0 до 12 результат floor(x / 2). Иные входы отклоняются.
Формула опирается на ранее обсуждавшееся правило; ограничения типа и диапазона заданы для упражнения. Максимум 12 — базовый учебный предел, без разрывов и других модификаций. Здесь не моделируются триггеры срыва, уменьшение шкалы или игровые последствия.

## M1 — «Три монеты»
Три независимые монеты, у каждой две стороны О и Р. Восемь упорядоченных исходов. При честных монетах каждый имеет вероятность 1/8.
Группировка по количеству О: 0 → 1 исход, 1 → 3, 2 → 3, 3 → 1. Значения успеха, тонких состояний и перебросов не задаются.

## G1 — бестиарий GRUNTWORK
Две вымышленные фракции: Городская стража и Контрабандисты. Четыре записи: Стражник, Контрабандист, Крыса и Бандит.
У Крысы фракции нет; у Бандита намеренно указана отсутствующая фракция 99. Это учебные данные, не утверждение о лоре.
База SQLite существует только в памяти; она не является схемой реального GRUNTWORK.
