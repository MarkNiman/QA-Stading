# Источники учебника
Проверены при подготовке 11 ноября 2026 года. Тексты уроков оригинальные; структура MDN используется как ориентир подачи.

| Источник | Использование |
|---|---|
| [MDN — A first splash into JavaScript](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/A_first_splash) | Цели, подготовка, пошаговый разбор примера |
| [MDN — Grammar and types](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Grammar_and_types) | Переменные и типы JS |
| [MDN — HTTP overview](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview) | Запросы, ответы, роль HTTP |
| [SQLite — SELECT](https://www.sqlite.org/lang_select.html) | Фильтрация, JOIN, порядок строк |
| [Playwright — assertions](https://playwright.dev/docs/test-assertions) | Проверки результата и повторение веб-проверок |
| [Git tutorial](https://git-scm.com/docs/gittutorial) | Состояние, staging, commit |
| [GitHub Actions](https://docs.github.com/en/actions/get-started/understand-github-actions) | Workflow, jobs, steps, runner |
