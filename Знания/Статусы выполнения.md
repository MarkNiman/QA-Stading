# Статусы выполнения
| Статус | Значение |
|---|---|
| NOT RUN | Проверка ещё не выполнялась |
| PASS | Фактический результат совпал с ожидаемым |
| FAIL | Зафиксировано расхождение с ожидаемым |
| BLOCKED | Проверку невозможно выполнить из-за препятствия |

Для BLOCKED укажите препятствие и условие разблокировки. Для FAIL зафиксируйте расхождение; затем разберите, подтверждается ли дефект или требуется уточнить ожидание.
Пример: [[TC-001 — Переход к следующему участнику]].
