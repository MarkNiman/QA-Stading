# Чек-лист
Чек-лист — компактный перечень проверок. Каждый пункт должен содержать понятную проверяемую мысль.

Он удобен для обзора покрытия. Для сложных условий и воспроизведения используйте [[Тест-кейс]].
Учебные кандидаты: обычный переход хода, конец очереди, ограничения прав. Их применимость требует сверки с требованиями.
Форма: [[Шаблон чек-листа]].
