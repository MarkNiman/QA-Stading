# Тестирование
Тестирование — деятельность по оценке качества продукта и выявлению проблем. Она включает анализ требований, проектирование проверок, выполнение и сообщение результатов.

Проверка сопоставляет фактическое поведение с обоснованным ожиданием. Успешная проверка подтверждает конкретный сценарий в конкретных условиях; она не доказывает отсутствие всех дефектов.

В [[RPG Codex]] можно исследовать, соответствует ли переход хода [[Требование|требованию]]. Сначала нужно выяснить правило перехода.
