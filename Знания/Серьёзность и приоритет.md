# Серьёзность и приоритет
Серьёзность (severity) описывает влияние дефекта. Приоритет (priority) — порядок его исправления с учётом целей команды.

Потеря состояния боя может иметь высокую серьёзность; конкретная срочность зависит от условий и выпуска. Шкалу и ответственных согласуют в проекте.
В [[Баг-репорт|баг-репорте]] обоснуйте влияние; не назначайте оценки только по личному впечатлению.
