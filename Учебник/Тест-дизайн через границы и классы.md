# Тест-дизайн через границы и классы
[[Учебник QA|Все статьи]] · Предыдущая: [[Тестовая документация на одном примере]] · Далее: [[Состояния и таблицы решений]]

**До начала:** [[Тестовая документация на одном примере]]. **Цель:** обоснованно выбирать данные вместо случайного набора. **Время:** 45–60 минут.

## Не все числа дают новые сведения
В упражнении «Просачивание» используем формулу силы срыва: floor(x / 2), где x — целое текущее значение от 0 до 12. Это модель P1 по ранее обсуждённому правилу; перед переносом в игру проверь актуальный канон.

Перебор всех тринадцати допустимых значений здесь дешёвый. Но сначала полезно понять структуру входа.

## Классы эквивалентности
В один класс объединяем значения, для которых предполагаем одинаковый способ обработки. Это рабочая гипотеза для выбора данных, а не доказательство одинакового поведения.

| Класс | Представитель | Ожидание P1 |
|---|---|---|
| Допустимое чётное целое | 6 | 3 |
| Допустимое нечётное целое | 7 | 3 |
| Целое ниже диапазона | -1 | Отклонить |
| Целое выше диапазона | 13 | Отклонить |
| Не целое число | 2.5 | Отклонить |
| Строка вместо числа | "6" | Отклонить |

Чётность интересна потому, что проверяет округление. Проверка только чётных значений не различит floor и округление к ближайшему целому на части входов.

## Граничные значения
Граница допустимого диапазона: 0 и 12. Ближайшие соседи: -1, 1, 11, 13. Набор охватывает обе стороны каждой границы. Дополнительно проверь 3 → 1: это удобный пример отличия floor от обычного округления.

Не смешивай все ошибки ввода в одном случае. Для значения "13" непонятно, что стало причиной отказа: тип или диапазон. Сначала изолируй условия.

## Когда полный перебор лучше выборки
В «Трёх монетах» всего восемь упорядоченных исходов: ООО, ООР, ОРО, РОО, ОРР, РОР, РРО, РРР. «Две одинаковые стороны» — группа из трёх исходов, а не один элементарный исход. Правила интерпретации успеха здесь не задаём.

Полный перебор хорош для маленького пространства. Если добавить роли, состояния и сетевые ошибки, комбинаций станет больше: понадобится приоритизация и анализ рисков.

## Попробуй
Составь набор для P1: шесть граничных значений и по одному представителю неверных типов. Для каждого укажи ожидаемый ответ и причину включения.

> [!tip]- Самопроверка
> Ожидания на границах: -1 — отказ; 0 → 0; 1 → 0; 11 → 5; 12 → 6; 13 — отказ. null, строка и дробь проверяют разные формы неверного ввода.

Готовность: можешь объяснить пользу каждого случая и назвать оставшийся риск. Далее рассматриваем комбинации условий.
