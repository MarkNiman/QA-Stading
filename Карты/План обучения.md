# План обучения
Исходный уровень: все шесть областей отмечены «Не изучено». Рабочий ориентир из последнего обсуждения: 12 недель, 5–7 часов в неделю. Это оценка нагрузки, а не обещание готовности к работе.

| Недели | Область | Проверяемый результат |
|---|---|---|
| 1–2 | Основы, ручное тестирование, документация | QA-001, тест-кейс, чек-лист, отчёт; баг-репорт при обнаружении дефекта |
| 3–4 | Тест-дизайн | Классы эквивалентности, границы, таблица решений и переходы состояний на функциях стенда |
| 5–6 | Web и API | Разбор запроса в DevTools, коллекция API с позитивными и негативными проверками |
| 7 | SQL и базы данных | SELECT, фильтрация, JOIN на учебных данных; сверка сохранённого состояния |
| 8–10 | TypeScript и Playwright | 5–10 устойчивых E2E-сценариев с осмысленными assertions |
| 11–12 | CI/CD и портфолио | Запуск проверок в CI, README с воспроизводимыми шагами и примерами работ |

Переход к следующему блоку — по выполненной практике и способности объяснить результат своими словами.
