# Учебные лаборатории
Это изолированные модели проектов, не исходники настоящего RPG Codex или GRUNTWORK.

Из корня репозитория:
```powershell
node --test labs/encounter.test.mjs
python labs/check_bestiary.py
```

Требования: Node.js 22+ для JS; Python 3 со стандартным sqlite3 для SQL.
Сторонних пакетов, сервера и токенов не требуется.

Контракты — [[Учебные модели проектов]]. Уроки: [[JavaScript на модели очереди]], [[SQL на бестиарии GRUNTWORK]].
ci-example.yml — неактивный пример; установка CI остаётся отдельным упражнением.
Готовые демонстрационные проверки не являются выполненными заданиями ученика.
