# QA Wiki
Рабочее Obsidian-хранилище для обучения Junior QA Engineer: Manual + AI Automation. Учебный стенд — RPG Codex.

Откройте папку этого репозитория в Obsidian: Open folder as vault. Начните с [[Главная]], затем [[Учебник QA]].
Хранилище работает без сторонних плагинов. На GitHub wiki-ссылки отображаются текстом; полноценная навигация доступна в Obsidian.

## Учебник прежде всего в Obsidian
Открой [[Главная]] → [[Интерактивный практикум]] → [[Урок QA — Ожидание до проверки]]. Первый модуль целиком доступен как связанные заметки без обязательного браузера и сторонних плагинов: выбор ветки разбора, подготовленные трассы A/B, упражнения на границы, рабочая тетрадь и баг-репорт прямо в vault.

Разборы и чекбоксы — ручная самопроверка, а не автоматическая оценка. Скопируй [[Рабочая тетрадь — Первый модуль QA]] и сохраняй свои ответы в копии. Wiki и прежние статьи сохранены.

Живой стенд `trainer/index.html` оставлен как [[Браузерный тренажёр — Дополнение|необязательное дополнение]]. Он запускается обычным браузером без сервера и зависимостей; на GitHub HTML виден как код. Основной учебный маршрут его не требует.

## Структура
- Карты — навигация и учебный маршрут.
- Учебник — последовательные статьи с разбором и упражнениями.
- Практикум — основной первый модуль в Obsidian: уроки, рабочая тетрадь и разборы.
- trainer — дополнительный живой браузерный стенд.
- labs — автономные учебные модели JS и SQL.
- Знания — статьи по одному понятию.
- Практика — задания и результаты на RPG Codex.
- Шаблоны — конспект, тест-кейс, баг-репорт, чек-лист и занятие.
- Журнал — история занятий.
- Источники — происхождение решений и открытые вопросы.
- Вложения — материалы проверок.
