# Первый интерактивный модуль
Открой index.html обычным браузером. Работает без сервера, CDN, установки и сети. HTML не следует вставлять в Markdown Obsidian: скрипты внутри заметок не выполняются. Смотри [[Интерактивный практикум]].

## Архитектура
- index.html / style.css: четыре урока и адаптивная раскладка.
- model.js: учебные модели C1/P1; C1 ограничен подготовленными валидными состояниями. A намеренно не увеличивает раунд, B намеренно игнорирует запрет роли.
- app.js: навигация по hash, обратная связь, черновик, localStorage, экспорт Markdown и JSON.
- model.test.cjs: проверки модели и сопоставление с существующим labs/encounter.mjs.
- dom.test.cjs: необязательные DOM-регрессии, требуют jsdom только разработчику.

Без сети и аналитики. Пользовательский текст выводится как текст, не как HTML. Произвольный JS не исполняется. Прогресс хранится под ключом qa-stading-trainer-v1. Импорт требует подтверждения замены. Черновик не записывается в исходные Markdown автоматически: ученик скачивает его сам.

## Проверки
Из корня репозитория:
```sh
node --check trainer/app.js
node --check trainer/model.js
node --test trainer/model.test.cjs labs/encounter.test.mjs
python labs/check_bestiary.py
```
Для необязательных DOM-проверок установи jsdom в отдельную временную папку и укажи её модуль через QA_JSDOM, либо установи jsdom локально без сохранения в зависимости проекта и запусти `node --test trainer/dom.test.cjs`. Для самого тренажёра это не нужно.

При выпуске пройди в браузере также: повторное нажатие, смену сборки/роли, сброс, пустую очередь, назад/вперёд, перезагрузку, отмену замены черновика, импорт/экспорт, узкий экран и клавиатурную навигацию. DOM-тест не заменяет визуальный просмотр браузера.
